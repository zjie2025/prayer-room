# 祷告小助手

写下代祷的事，安静等候片刻，生成一篇祷告词，并带领你一起祷告。

## 用法

1. **写下代祷的事**：选一个类别（感恩、家人、健康、工作、学业、教会、其他），写下想说的话，可填可不填名字。
2. **等候**：60 秒安静等候，配一节与类别对应的经文；等不及可以点「不等了，直接生成」。
3. **生成祷告词**：按模板生成一篇完整的祷告词——称呼、感恩、你的原话、按类别写的祈求、一节经文、交托与结尾。
4. **带领祷告**：点「带领我祷告」，浏览器会一句一句朗读祷告词（中文语音），当前读到的句子会高亮；可以暂停、继续、调慢速。还可以复制祷告词，或再写一个。

「我的祷告记录」只保存在这台设备的浏览器里（localStorage），可以查看、单条删除或全部清空。

## 隐私

内容只保存在你的浏览器，**不会上传**到任何服务器，也不会发给任何人。本站是纯静态页面，没有后端、没有统计、没有广告。

## 技术

- 单个 `index.html`，无构建、无依赖、无费用。
- 经文全部引自和合本圣经（CUV），逐字核对过。
- 朗读用浏览器内置 `speechSynthesis`（zh-CN），手机、电脑都可用。
- 配色沿用长岛联合圣经教会网站：深青 #16323C、酒红 #7A1E2E、金色 #C9A227。

## 部署

GitHub Pages：把 `index.html` 放在仓库根目录，开启 Pages（Deploy from a branch，选 main 分支）即可访问。
